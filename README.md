# WhatsApp Bot (Baileys)

Bot de WhatsApp configurado para rodar gratuitamente no **Render**.

## Como Usar
1. Faça o download ou clone este repositório.
2. Suba o código para o seu **GitHub**.
3. Crie um **Web Service** no [Render](https://render.com).
4. Configure os comandos:
   - **Environment:** `Node`
   - **Build Command:** `npm install`
   - **Start Command:** `npm start`
5. Acesse a aba **Logs** no painel do Render para visualizar o QR Code e conectar seu WhatsApp!
